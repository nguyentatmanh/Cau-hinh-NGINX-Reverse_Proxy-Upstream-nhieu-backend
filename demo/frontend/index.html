Tại sao Peer IP luôn là 172.x.x.x?

Vì Client kết nối tới NGINX Gateway, sau đó NGINX thiết lập kết nối TCP mới tới container Backend. Do đó Socket IP của Node.js luôn là IP container NGINX. Đó là lý do bắt buộc phải có chỉ thị proxy_set_header X-Real-IP $remote_addr;.

Cảnh báo Bảo mật IP Spoofing:

Kẻ tấn công có thể chèn header giả mạo nếu kết nối trực tiếp vào backend. Backend chỉ được tin tưởng các header chuyển tiếp khi request bắt nguồn từ IP của Reverse Proxy đáng tin cậy.
